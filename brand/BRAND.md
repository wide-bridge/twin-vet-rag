# TwinVet Care 브랜드 기준

2026-11-09 · 제공 로고를 바탕으로 정리한 웹·모바일 UI 색상안

## 이름과 로고

- 서비스명은 **TwinVet Care**로 통일한다.
- `twinvet-logo-original.png`는 사용자가 제공한 TwinVet 로고 원본이다. 원본에는 Care가 없으므로 완성된 TwinVet Care 통합 로고로 오인하지 않는다.
- 앱 헤더에서는 원본 로고 옆에 `Care`를 실제 텍스트로 배치한다. 좁은 모바일 화면에서는 로고 크기를 줄이되 비율을 유지한다. 이미지 안에 Care를 임의로 그려 넣지 않는다.
- **Care 크기·위치 규칙**(`brand-lockup.css`): 원본 로고(683×283px)를 실측해 Care의 대문자 높이를 워드마크 `T`·`V`의 높이(로고 너비의 17.7%)와 같게, 기준선을 워드마크 기준선(이미지 아래에서 로고 너비의 4.8% 위)에 맞춘다. 글꼴은 워드마크와 비슷한 둥근 산세리프 Nunito 700, 색은 TwinVet Purple. 로고 너비 변수 `--logo-w` 하나로 전체가 함께 커지고 줄어들며, Care가 다음 줄로 넘어가지 않는다. 기본 너비는 화면 폭의 45%(최소 150px, 최대 340px)로 320px 화면에서도 한 줄에 들어간다.
- 로고를 늘이거나 자르거나 색을 바꾸지 않는다. 밝은 흰색 배경에서 사용하고 주변에 충분한 여백을 둔다. 작은 크기에서 식별이 어려우면 서비스명을 텍스트로 표시한다.
- 접근 가능한 이름은 TwinVet Care로 제공한다. 로고 대체텍스트와 인접 Care 텍스트가 중복 낭독되지 않게 한다.
- `references/`의 PoochPaw·wigglo 이미지는 색상 참고용이다. 세 브랜드 로고를 하나로 합치거나 서비스의 제휴·소유 관계를 표현하지 않는다.

## 색상 연결

TwinVet의 보라·파랑을 중심으로 한다. PoochPaw의 네이비·코랄에서 차분한 글자색과 따뜻한 포인트를, wigglo의 초록·주황에서 보조 포인트를 가져온다. 여러 브랜드 색을 같은 비중으로 사용하지 않는다.

제공 이미지는 색 변화·안티앨리어싱을 포함한다. 아래 HEX는 이미지의 주요 색을 참고해 정리한 **디지털 UI 제안값**이며 원본 브랜드의 공식 색상 규정은 아니다.

| 역할 | 색상 | 사용 위치 |
|---|---|---|
| 주요 행동 / TwinVet Blue | `#0060C0` | 상담 시작·보내기 버튼, 링크, 선택 표시 |
| 브랜드 / TwinVet Purple | `#402878` | 주요 제목, 브랜드 강조, AI 답변 표시 |
| 기본 글자 / Deep Navy | `#102858` | 본문·아이콘. 두 참고 브랜드의 네이비 계열과 연결 |
| 따뜻한 포인트 / Pooch Coral | `#F86860` | 작은 하트·돌봄 강조·장식. 주요 버튼에 혼용하지 않음 |
| 생기 / Leaf Green | `#58B828` | 작은 브랜드 포인트. 작은 글자색으로 사용하지 않음 |
| 주의 포인트 / Warm Orange | `#FF7000` | 안내 아이콘·장식. 응급·오류와 구분 |
| 화면 배경 | `#F7F9FC` | 전체 페이지 |
| 표면 | `#FFFFFF` | 대화·입력·출처 패널 |
| 보조 글자 | `#526078` | 설명·메타정보 |
| 구분선 | `#DCE3EE` | 영역 구분용. 입력 경계는 더 진한 `#7A879A` 사용 |

화면의 대부분은 흰색·연한 배경·네이비 글자다. 파랑은 행동, 보라는 브랜드, 코랄·초록·주황은 작은 보조 포인트에 제한한다. 모바일과 PC에 같은 토큰을 사용한다.

## 상태·접근성

- 주요 버튼: 파랑 바탕 + 흰 글자. hover/pressed는 `#004E9E`로 어둡게 한다.
- 성공: `#246B32` 글자 + `#EDF7EE` 배경.
- 주의: `#8A4500` 글자 + `#FFF3E6` 배경.
- 오류·응급 고정 안내: `#B42318` 글자 + `#FFF0EE` 배경. 코랄 장식과 구분한다.
- 포커스: 파랑 2px 외곽선과 흰색 간격을 사용한다. 색만으로 상태를 전달하지 않고 문구·아이콘을 함께 제공한다.
- 코랄·밝은 초록·주황 위의 흰색 작은 글자는 사용하지 않는다. 실제 디자인에서는 본문 대비 4.5:1 이상, UI 경계·포커스 대비 3:1 이상을 확인한다.
- 다크 모드는 이번 기준에 포함하지 않는다. 운영 화면에서 수의사 참여·검토 완료 여부를 색만으로 표시하지 않는다.

## 개발 적용

- `brand-tokens.css`는 프레임워크와 무관한 CSS 변수 기준이다. React 프론트에 연결할 때 기존 스타일과 비교해 적용한다.
- `palette.html`은 로컬에서 열어 보는 색상·로고 미리보기다. 실제 서비스 화면 구현물이 아니다.
- 이미지 원본은 그대로 보관한다. PoochPaw·wigglo 참고 로고는 서비스 번들에 자동 포함하지 않는다.
- 화면 배치·입력·오류 처리는 `../docs/05_화면설계서.md`를 따른다.
