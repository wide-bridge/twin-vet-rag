description

반려견(강아지)의 일반 건강 질문을 도와드려요. 내과·외과·피부·눈·치아 관련 상담 자료를 바탕으로 답합니다.

stethoscope

AI가 상담 사례와 수의학 자료를 찾아 정리한 정보예요. 진단이나 처방이 아니며, 정확한 판단은 동물병원에서 받으세요.

lock_clock

질문과 입력한 반려견 정보는 답변을 위해 저장돼요. 이 브라우저에서 7일간 볼 수 있고 이후 자동 삭제되며, 언제든 직접 삭제할 수 있어요.

error_outline

응급 상황이면 AI 답변을 기다리지 마세요.
