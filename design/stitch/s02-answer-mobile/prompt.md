# S02 근거 있는 답변 · 모바일 (MOBILE)

TwinVet Care: Korean responsive web service for dog guardians. AI organizes health information from consultation cases and veterinary references; it is NOT diagnosis, prescription or a vet chat. Use the project design system for all colors, fonts and radii. All UI text in Korean, exactly as given below; do not invent features, promises or extra copy. Header shows the brand text 'TwinVet Care' (Twin and Care purple, Vet blue). Do NOT include: login, conversation history sidebar, animal-type selector, life-stage labels or age ranges, vet-verified badges, live vet chat, image/voice input, booking, star ratings, AI mascot or avatar, doctor imagery, triage/urgency badges, quoted source passages.

Consultation screen after the first answer, mobile 390px:
1. Header 'TwinVet Care' with menu icon.
2. Read-only summary chip row: '말티즈 · 10세 3개월 · 3.2kg' (pill shape, no other labels).
3. User message bubble aligned right: '어제부터 하루에 두 번 토했어요. 밥은 조금 먹어요. 병원에 가야 할까요?'
4. AI answer card aligned left, labeled with a small tag 'AI 답변': three short paragraphs and a bullet list summarizing that repeated vomiting should be watched for dehydration, lethargy and blood, and a sentence '입력하신 10세 말티즈 기준으로…'. Below the text, source chips: '근거 1 · 상담 사례 · 내과', '근거 2 · 전문 자료 · 내과'. Below that, three small buttons: '도움 됐어요', '아쉬워요', '의견 남기기'.
5. A second user question bubble and a processing AI card with a subtle loading indicator and text '답변을 준비하고 있어요'.
6. Bottom fixed bar: one-line emergency notice, text input disabled while processing, '보내기' disabled.
