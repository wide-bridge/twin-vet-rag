# S01 시작 · 모바일 (MOBILE)

TwinVet Care: Korean responsive web service for dog guardians. AI organizes health information from consultation cases and veterinary references; it is NOT diagnosis, prescription or a vet chat. Use the project design system for all colors, fonts and radii. All UI text in Korean, exactly as given below; do not invent features, promises or extra copy. Header shows the brand text 'TwinVet Care' (Twin and Care purple, Vet blue). Do NOT include: login, conversation history sidebar, animal-type selector, life-stage labels or age ranges, vet-verified badges, live vet chat, image/voice input, booking, star ratings, AI mascot or avatar, doctor imagery, triage/urgency badges, quoted source passages.

Start screen, mobile 390px, single column, 16px side margins, vertical order:
1. Header: brand text 'TwinVet Care'.
2. Title (headline): '반려견 건강 궁금증, 상담 자료로 함께 찾아봐요'.
3. Info block with small icons, three short paragraphs: (a) '반려견(강아지)의 일반 건강 질문을 도와드려요. 내과·외과·피부·눈·치아 관련 상담 자료를 바탕으로 답합니다.' (b) 'AI가 상담 사례와 수의학 자료를 찾아 정리한 정보예요. 진단이나 처방이 아니며, 정확한 판단은 동물병원에서 받으세요.' (c) '질문과 입력한 반려견 정보는 답변을 위해 저장돼요. 이 브라우저에서 7일간 볼 수 있고 이후 자동 삭제되며, 언제든 직접 삭제할 수 있어요.'
4. Emergency box (light red background, red text, warning icon): title '응급 상황이면 AI 답변을 기다리지 마세요.' body '호흡 곤란, 의식 저하, 경련, 심한 출혈, 중독 의심 등은 바로 동물병원(야간에는 24시 동물병원)에 연락하세요.'
5. Full-width primary button '상담 시작'.
No photos, no illustrations except one small optional dog line icon near the title.
