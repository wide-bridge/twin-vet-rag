# S02 답변 상태 4종 · 모바일 (MOBILE)

TwinVet Care: Korean responsive web service for dog guardians. AI organizes health information from consultation cases and veterinary references; it is NOT diagnosis, prescription or a vet chat. Use the project design system for all colors, fonts and radii. All UI text in Korean, exactly as given below; do not invent features, promises or extra copy. Header shows the brand text 'TwinVet Care' (Twin and Care purple, Vet blue). Do NOT include: login, conversation history sidebar, animal-type selector, life-stage labels or age ranges, vet-verified badges, live vet chat, image/voice input, booking, star ratings, AI mascot or avatar, doctor imagery, triage/urgency badges, quoted source passages.

Mobile 390px design sheet titled '답변 상태' showing four AI answer card variants stacked vertically, each clearly different through icon, title text and border style (not color alone), none with source chips:
1. Clarification card, question icon, title '정확히 안내하려면 조금 더 알려주세요', body '토한 내용물에 피나 이물질이 보였나요? 기운이나 식욕은 평소와 비교해 어떤가요?'.
2. Insufficient evidence card, muted dashed border, info icon, title '확인할 수 있는 자료가 부족해요', body '증상·기간·상황을 더 구체적으로 적어 주시거나 동물병원에 문의해 주세요.'.
3. Out of scope card, neutral, info icon, title '반려견 건강 질문만 도와드릴 수 있어요', body '고양이나 다른 동물, 건강과 관계없는 질문에는 답하지 않아요.'.
4. Failure card, error icon, red text '답변을 가져오지 못했어요', with a secondary button '다시 시도'; the user's question above it stays visible.
Each card keeps the small 'AI 답변' tag except the failure card.
